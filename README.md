# RockPaperScissors
A simple console game created whilst learning the fundamentals of C#.
## Description
An application that allows the user to play "rock, paper, scissors" against a computer opponent. The user enters their choice and the program randomly selects between rock, paper, or scissors. The program determines the winner, keeps track of scores for both the player and the computer, and allows the user to continue playing after the round ends.
## Concepts used
-Variables and data types
-'while' loops
-'if'/'else if' statements
-'switch case' statements
-Random number generation
-Score tracking
